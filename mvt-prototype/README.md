# MVT Prototype

This is a front-end prototype for a Minimum Viable Toolkit portal.

Features:
- Register/login with email and password (stored locally).
- Enter your current Minimum Viable Toolkit and monthly AI highlight.
- Search across users, toolkits and highlights.
- Like AI highlights and view a leaderboard sorted by likes.
- Reminder simulated via console log if monthly highlight is missing after the first workday.

## Usage
Open `index.html` in a modern browser.
